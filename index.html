Cloudiste PAD est une mini plateforme de cloud gaming autonome : un seul script déploie Sunshine sur une VM GPU, et Moonlight sert de client. Pas de compte, pas de base de données, pas d’interface à administrer.

Voir le marché GPU en direct Voir le comparatif GPU

Pensé pour un usage perso

Une machine, un utilisateur, zéro backend.

Un seul script

bash deploy.sh deploy installe Docker, le NVIDIA Container Toolkit, génère la configuration et lance Sunshine.

Moonlight + Sunshine

On réutilise l’image officielle Cloudypad Sunshine. Le client reste le célèbre Moonlight, sur PC ou mobile.

Tailscale par défaut

Accès privé à la VM sans ouvrir les ports aléatoires de Vast.ai et sans casser le pairing Moonlight.

NVENC H.264 / HEVC

L’encodage matériel est activé sur les GPU NVIDIA compatibles, avec repli logiciel si besoin.

Aucun compte

Un seul utilisateur, un mot de passe local généré dans /opt/cloudypad/.env. Rien n’est envoyé dans le cloud.

Documenté

Un tutoriel Vast.ai accompagne le déploiement, du SSH jusqu’au premier lancement de Moonlight.

Fork de Cloudypad

Cloudiste PAD est un fork / dérivé de Cloudypad créé par PierreBeucher. Il réutilise l’image Docker officielle ghcr.io/pierrebeucher/cloudypad/sunshine:0.46.0 et s’appuie sur Sunshine et Moonlight.

Ce fork simplifie le projet pour un cas d’usage unique : une VM GPU louée chez Vast.ai, un seul joueur, et un déploiement direct par script. Ce n’est pas un produit officiel Cloudypad. Le code d’origine est distribué sous licence AGPL-3.0 ; cette source est donc fournie conformément à cette licence.

Démarrage rapide

Sur une VM Ubuntu avec driver NVIDIA déjà installé :

curl -fsSL https://raw.githubusercontent.com/nazimboudeffa/cloudiste-pad/main/deploy.sh -o deploy.sh
bash deploy.sh deploy
  1. Connecte la VM et ton PC au même réseau Tailscale.
  2. Récupère l’IP avec tailscale ip -4.
  3. Ouvre https://<IP-Tailscale>:47990 et connecte-toi avec cloudy.
  4. Dans Moonlight, ajoute l’IP Tailscale et saisis le PIN affiché dans Sunshine.

Le détail de chaque étape est dans le tutoriel Vast.ai.
