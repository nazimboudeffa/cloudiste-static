Ce projet est à un stade expérimental.

CloudistePAD est une mini plateforme de cloud gaming autonome : un seul script déploie Sunshine sur une VM Ubuntu complète avec GPU NVIDIA, et Moonlight sert de client. Pas de compte, pas de base de données, pas d’interface à administrer.

Script CloudistePAD et offres GPU : bien distinguer

Le script déploie un serveur de jeu sur une machine complète. Le marché GPU et le comparatif recensent des offres de location : un prix de GPU ne garantit pas une machine compatible.

Ce qu’attend le script

Une VM Ubuntu x86_64 complète (pas un pod ni un conteneur), avec SSH et root/sudo, pilote NVIDIA et nvidia-smi fonctionnels, Docker et un GPU NVIDIA compatible NVENC. Le réseau doit permettre la connexion Moonlight : Tailscale par défaut, ou ports UDP dédiés ouverts.

Ce que montre le marché

Des prix de GPU à la demande, par GPU et par heure, chez Vast.ai et Runpod. Peuvent y figurer des GPU datacenter, des machines multi-GPU ou des offres conteneurisées. Le prix affiché exclut CPU, RAM, disque, réseau et taxes, et ne valide pas la compatibilité CloudistePAD.

Avant de lancer deploy.sh : vérifie que l’offre est bien une VM complète, que le disque est persistant et que les besoins réseau sont couverts. Le comparatif détaille les verdicts par fournisseur et sa checklist avant location : par exemple, Runpod est déconseillé tant que les contraintes VM/UDP ne sont pas confirmées, malgré sa présence dans le marché GPU.

Pensé pour un usage perso

Une machine, un utilisateur, zéro backend.

Un seul script

bash deploy.sh deploy installe Docker, le NVIDIA Container Toolkit, génère la configuration et lance Sunshine.

Moonlight + Sunshine

On réutilise l’image officielle Cloudypad Sunshine. Le client reste le célèbre Moonlight, sur PC ou mobile.

Tailscale par défaut

Accès privé à la VM sans ouvrir les ports aléatoires de Vast.ai et sans casser le pairing Moonlight.

NVENC H.264 / HEVC

L’encodage matériel est activé sur les GPU NVIDIA compatibles, avec repli logiciel si besoin.

Aucun compte

Un seul utilisateur, un mot de passe local généré dans /opt/cloudypad/.env. Rien n’est envoyé dans le cloud.

Documenté

Un tutoriel Vast.ai sert d’exemple de déploiement, du SSH jusqu’au premier lancement de Moonlight ; il ne limite pas le script à ce fournisseur.

Fork de Cloudypad

CloudistePAD est un fork / dérivé de Cloudypad créé par PierreBeucher. Il réutilise l’image Docker officielle ghcr.io/pierrebeucher/cloudypad/sunshine:0.46.0 et s’appuie sur Sunshine et Moonlight.

Ce fork simplifie le projet pour un cas d’usage unique : une VM complète avec GPU NVIDIA, un seul joueur, et un déploiement direct par script. Le tutoriel Vast.ai illustre ce cas, mais tous les fournisseurs ne louent pas une VM compatible (voir le comparatif). Ce n’est pas un produit officiel Cloudypad. Démarrage rapide

Sur une VM Ubuntu complète (x86_64) avec accès SSH/root et driver NVIDIA déjà installé :

curl -fsSL https://raw.githubusercontent.com/nazimboudeffa/cloudiste-pad/main/deploy.sh -o deploy.sh
bash deploy.sh deploy
  1. Connecte la VM et ton PC au même réseau Tailscale.
  2. Récupère l’IP avec tailscale ip -4.
  3. Ouvre https://<IP-Tailscale>:47990 et connecte-toi avec cloudy.
  4. Dans Moonlight, ajoute l’IP Tailscale et saisis le PIN affiché dans Sunshine.

Une offre du marché GPU n’est pas forcément une telle VM : vérifie la nature de l’instance, l’accès SSH et la persistance du disque avant de lancer le script. Le détail de chaque étape est dans le tutoriel Vast.ai.
