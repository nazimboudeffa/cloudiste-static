Générez d’abord le fichier d’offres depuis le script.

python scan_gpu.py --taux-eur 0.86 --json gpu-market.json

Les variables VAST_API_KEY et RUNPOD_API_KEY doivent être définies. Si vous ouvrez cette page en local, servez le dossier avec python -m http.server 8000 : les navigateurs bloquent la lecture du JSON en file://.

Certaines offres n’intègrent pas de prix EUR : la conversion est indicative, calculée avec 1 USD ≈ 0,86 EUR. Pour figer le taux, relancez le script avec --taux-eur 0.86.

Méthode : prix par GPU et par heure, hors CPU, RAM, disque, réseau, taxes et frais de stockage. Le script ne retient que les offres disponibles à la demande dont la machine est en France.

Les noms de GPU renvoient vers l’offre du fournisseur : déploiement Runpod pré-rempli ou marketplace Vast.ai. Dans le tableau récapitulatif, le lien pointe vers l’offre la moins chère du modèle. Aucun lien d’affiliation sur cette page.

Les offres marketplace changent vite : vérifiez toujours le prix final, la VM complète, l’accès SSH, les ports UDP de Sunshine et la persistance du disque avant de louer.
